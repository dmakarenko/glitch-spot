# Glitch Spot v0.1 — Foundation Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Reference scope:** `docs/seeds/2026-05-21-glitch-spot-v1-scope-seed.md` (working scope) and `docs/seeds/2026-05-21-glitch-spot-seed.md` (original PRD).

**Goal:** Build the foundation slice of Glitch Spot v0.1: pressing a global hotkey captures the active monitor and shows a transparent, always-on-top overlay window displaying the screenshot. No drawing, no notes, no save, no MCP — just the substrate the rest of v0.1 will build on.

**Architecture:** A Tauri 2 desktop app with a Rust core and a React + Vite + TypeScript webview. The Rust core owns OS integrations (screen capture via `screencapturekit`, global hotkey via `tauri-plugin-global-shortcut`, window lifecycle). The webview renders the overlay UI (eventually canvas-based drawing; in this slice, just a static screenshot backdrop). Two Tauri windows: a small main/settings window (placeholder in this slice) and an overlay window spawned on demand.

**Tech Stack:** Tauri 2, Rust (stable), React 18, Vite 5, TypeScript 5, `screencapturekit` crate (macOS), `tauri-plugin-global-shortcut`. macOS 13+ (the floor for ScreenCaptureKit feature set we rely on).

---

## Scope

**In scope for this plan:**

1. Tauri 2 + React + Vite project scaffold under the existing `glitch-spot` repo.
2. Spike + module for macOS screen capture of the active monitor as a PNG.
3. Spike + module for spawning a transparent, always-on-top, borderless overlay window sized to the active monitor.
4. Spike + module for registering a global hotkey (default `Cmd+Shift+G`).
5. End-to-end wire-up: hotkey press → capture → show overlay with screenshot → `Esc` dismisses.

**Explicitly out of scope (deferred to subsequent plans):**

- Drawing rectangles, per-rectangle notes, undo.
- Snapshot JSON assembly, annotated-PNG generation, filesystem persistence.
- Clipboard writing.
- The MCP HTTP/stdio server (decision deferred — see scope seed §11 follow-up).
- First-run UX (TCC permission gating beyond what's needed to make capture work in dev).
- Multi-monitor support (active monitor only).
- Save / Discard modal (`Esc` simply dismisses in this slice).
- Packaging / codesigning / installers.

```rust
//! ABOUTME: One-off spike for ScreenCaptureKit integration.
//! ABOUTME: Captures the first available display once and writes /tmp/glitch-spot-spike.png.

use std::path::PathBuf;

#[tauri::command]
pub async fn spike_capture() -> Result<PathBuf, String> {
    use screencapturekit::shareable_content::SCShareableContent;
    use screencapturekit::stream::configuration::SCStreamConfiguration;
    use screencapturekit::stream::content_filter::SCContentFilter;
    // The actual API may name these slightly differently in 0.3.x — adjust here.

    let content = SCShareableContent::get().map_err(|e| format!("shareable content: {e:?}"))?;
    let display = content
        .displays()
        .first()
        .cloned()
        .ok_or_else(|| "no display found".to_string())?;

    let config = SCStreamConfiguration::new()
        .set_width(display.width() as u32)
        .map_err(|e| format!("config width: {e:?}"))?
        .set_height(display.height() as u32)
        .map_err(|e| format!("config height: {e:?}"))?;

    let filter = SCContentFilter::new().with_display_excluding_windows(&display, &[]);

    // Pull a single frame synchronously (the crate likely exposes a stream; for the spike we want
    // the simplest sample). If the crate provides `capture_one`, use it. Otherwise spin up a
    // stream, take one frame, stop.
    let frame_bytes = screencapturekit::capture_one(&filter, &config)
        .map_err(|e| format!("capture: {e:?}"))?;

    let img = image::load_from_memory(&frame_bytes)
        .or_else(|_| {
            // Fall back to interpreting as raw RGBA if the crate returns BGRA bytes.
            let buf = image::RgbaImage::from_raw(
                display.width() as u32,
                display.height() as u32,
                frame_bytes,
            )
            .ok_or("bad raw buffer")?;
            Ok::<_, &'static str>(image::DynamicImage::ImageRgba8(buf))
        })
        .map_err(|e| format!("decode: {e}"))?;

    let out = PathBuf::from("/tmp/glitch-spot-spike.png");
    img.save(&out).map_err(|e| format!("save: {e}"))?;
    Ok(out)
}
```

```rust
//! ABOUTME: Public screen-capture API for Glitch Spot. OS-agnostic surface; impls behind cfg.
//! ABOUTME: Currently macOS-only (v0.1); Windows lands in v1.

use serde::{Deserialize, Serialize};

#[cfg(target_os = "macos")]
mod macos;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct CapturedFrame {
    pub width: u32,
    pub height: u32,
    pub scale_factor: f32,
    /// PNG-encoded bytes.
    #[serde(with = "serde_bytes")]
    pub png: Vec<u8>,
    /// Index of the captured monitor in the OS's display list.
    pub display_index: usize,
}

#[derive(Debug, thiserror::Error)]
pub enum CaptureError {
    #[error("no display found")]
    NoDisplay,
    #[error("platform error: {0}")]
    Platform(String),
    #[error("encoding error: {0}")]
    Encoding(String),
}

#[cfg(target_os = "macos")]
pub fn capture_active_monitor() -> Result<CapturedFrame, CaptureError> {
    macos::capture_active_monitor()
}

#[cfg(not(target_os = "macos"))]
pub fn capture_active_monitor() -> Result<CapturedFrame, CaptureError> {
    Err(CaptureError::Platform("only macOS is supported in v0.1".into()))
}
```

- [ ] **Step 5: Create `src-tauri/src/capture/macos.rs` from the spike.**

Take the working API calls discovered in M2 and put them behind `capture_active_monitor`. The function must:

- Detect the display containing the current mouse cursor (use Tauri 2's `Manager::monitor_at_pos` or query Cocoa's `NSScreen::mainScreen` / `NSEvent::mouseLocation` via `objc2`/`cocoa`).
- Capture *only* that display.
- Return PNG bytes encoded via the `image` crate.

```rust
//! ABOUTME: macOS-specific screen capture using ScreenCaptureKit.
//! ABOUTME: Captures the monitor under the current cursor position.

use super::{CapturedFrame, CaptureError};
use image::ImageEncoder;
use std::io::Cursor;

pub(super) fn capture_active_monitor() -> Result<CapturedFrame, CaptureError> {
    let cursor_pos = cursor_position_global()?;
    let displays = list_displays()?;
    let (index, display) = displays
        .into_iter()
        .enumerate()
        .find(|(_, d)| d.contains_point(cursor_pos))
        .ok_or(CaptureError::NoDisplay)?;

    let raw = capture_display_pixels(&display)?; // returns RGBA Vec<u8>
    let mut png = Vec::with_capacity(raw.len() / 4);
    image::codecs::png::PngEncoder::new(Cursor::new(&mut png))
        .write_image(
            &raw,
            display.width(),
            display.height(),
            image::ExtendedColorType::Rgba8,
        )
        .map_err(|e| CaptureError::Encoding(e.to_string()))?;

    Ok(CapturedFrame {
        width: display.width(),
        height: display.height(),
        scale_factor: display.scale_factor(),
        png,
        display_index: index,
    })
}
```

```rust
//! ABOUTME: Overlay window lifecycle: position over active monitor, show, hide.
//! ABOUTME: Reads cursor position to pick the monitor, then sizes the "overlay" window to it.

use tauri::{Manager, PhysicalPosition, PhysicalSize, WebviewWindow};

const OVERLAY_LABEL: &str = "overlay";

#[derive(Debug, thiserror::Error)]
pub enum OverlayError {
    #[error("overlay window not found")]
    WindowMissing,
    #[error("no monitor found at cursor")]
    NoMonitor,
    #[error("tauri error: {0}")]
    Tauri(#[from] tauri::Error),
}

pub fn show_over_active_monitor(app: &tauri::AppHandle) -> Result<(), OverlayError> {
    let window: WebviewWindow = app.get_webview_window(OVERLAY_LABEL).ok_or(OverlayError::WindowMissing)?;

    // Tauri 2 exposes monitors via app.available_monitors() and a cursor-position helper:
    let cursor = app.cursor_position()?;
    let monitor = app
        .available_monitors()?
        .into_iter()
        .find(|m| {
            let pos = m.position();
            let size = m.size();
            let x_in = cursor.x >= pos.x as f64 && cursor.x < (pos.x as i32 + size.width as i32) as f64;
            let y_in = cursor.y >= pos.y as f64 && cursor.y < (pos.y as i32 + size.height as i32) as f64;
            x_in && y_in
        })
        .ok_or(OverlayError::NoMonitor)?;

    window.set_position(PhysicalPosition::new(monitor.position().x, monitor.position().y))?;
    window.set_size(PhysicalSize::new(monitor.size().width, monitor.size().height))?;
    window.show()?;
    window.set_focus()?;
    Ok(())
}

pub fn hide(app: &tauri::AppHandle) -> Result<(), OverlayError> {
    let window = app.get_webview_window(OVERLAY_LABEL).ok_or(OverlayError::WindowMissing)?;
    window.hide()?;
    Ok(())
}
```

> Tauri 2's `AppHandle::cursor_position()` API existed as of late 2024. If the implementer finds it's named differently, adjust. The spike pattern applies here too.

```tsx
import { useEffect, useState } from "react";
import { listen } from "@tauri-apps/api/event";
import { invoke } from "@tauri-apps/api/core";

type Frame = {
  width: number;
  height: number;
  scale_factor: number;
  png: number[]; // serde_bytes serializes to a number array in JSON
  display_index: number;
};

export function Overlay() {
  const [imageUrl, setImageUrl] = useState<string | null>(null);

  useEffect(() => {
    const unlisten = listen<Frame>("glitch-spot://frame", (event) => {
      const bytes = new Uint8Array(event.payload.png);
      const blob = new Blob([bytes], { type: "image/png" });
      setImageUrl((prev) => {
        if (prev) URL.revokeObjectURL(prev);
        return URL.createObjectURL(blob);
      });
    });

    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") invoke("hide_overlay");
    };
    window.addEventListener("keydown", onKey);

    return () => {
      unlisten.then((fn) => fn());
      window.removeEventListener("keydown", onKey);
    };
  }, []);

  return (
    <div
      style={{
        position: "fixed",
        inset: 0,
        background: imageUrl ? `center / cover no-repeat url(${imageUrl})` : "rgba(0,0,0,0.05)",
      }}
    />
  );
}
```

```rust
//! ABOUTME: Global-hotkey registration. Default Cmd+Shift+G triggers overlay capture.
//! ABOUTME: Configurable per-user in a later slice.

use tauri::{AppHandle, Manager};
use tauri_plugin_global_shortcut::{Code, GlobalShortcutExt, Modifiers, Shortcut};

pub const DEFAULT_HOTKEY: Shortcut = Shortcut::new(
    Some(Modifiers::SUPER | Modifiers::SHIFT),
    Code::KeyG,
);

pub fn register(app: &AppHandle) -> tauri::Result<()> {
    let handle = app.clone();
    app.global_shortcut().on_shortcut(DEFAULT_HOTKEY, move |_app, _shortcut, _event| {
        let handle = handle.clone();
        tauri::async_runtime::spawn(async move {
            if let Err(e) = crate::trigger_overlay(&handle).await {
                eprintln!("trigger_overlay failed: {e}");
            }
        });
    })?;
    Ok(())
}
```

```rust
pub(crate) async fn trigger_overlay(app: &tauri::AppHandle) -> anyhow::Result<()> {
```
