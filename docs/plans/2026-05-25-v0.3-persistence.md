# Glitch Spot v0.3 — Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Part of initiative:** [`docs/initiatives/glitch-spot/INITIATIVE.md`](../initiatives/glitch-spot/INITIATIVE.md)
> **Design seed:** [`docs/initiatives/glitch-spot/v0.3-persistence-seed.md`](../initiatives/glitch-spot/v0.3-persistence-seed.md)

**Goal:** Persist snapshot JSON + clean PNG + annotated PNG to `~/.glitch-spot/snapshots/{id}/` and sweep dirs older than 24h on app startup.

**Architecture:** Refactor `snapshot::build::build_and_write` into a pure `snapshot::build::build` returning a new `BuiltSnapshot { snapshot, clean_bytes, annotated_bytes }`. Move all filesystem I/O into a new `snapshot::persist` module exposing `snapshots_dir`, `write`, and `cleanup`. Update `lib.rs::save_snapshot` to call `build → publish → write` and add a synchronous cleanup pass at the top of `run()`.

**Tech Stack:** Rust, existing `std::fs` + `chrono` + `uuid`. Dev-only: `tempfile = "3"`, `filetime = "0.2"`.

```rust
use std::env;
use std::io;
use std::path::PathBuf;
use std::time::Duration;

pub const MAX_AGE: Duration = Duration::from_secs(24 * 60 * 60);

/// Returns `~/.glitch-spot/snapshots/`, creating it (and `.glitch-spot/`) if absent.
///
/// Resolves `$HOME` directly (macOS-only product). Returns `io::Error::NotFound`
/// equivalent (kind = `NotFound`) if `HOME` is unset.
pub fn snapshots_dir() -> io::Result<PathBuf> {
    let home = env::var("HOME")
        .map_err(|_| io::Error::new(io::ErrorKind::NotFound, "HOME is not set"))?;
    let dir = PathBuf::from(home).join(".glitch-spot").join("snapshots");
    std::fs::create_dir_all(&dir)?;
    Ok(dir)
}
```

```rust
use crate::snapshot::build::BuiltSnapshot;
use std::path::Path;

/// Writes the three files (`clean.png`, `annotated.png`, `snapshot.json`)
/// to `{base}/{built.snapshot.id}/`. If any per-file write fails, attempts
/// to remove the `{id}/` directory so callers never observe a partial state,
/// then propagates the original error.
pub fn write(base: &Path, built: &BuiltSnapshot) -> io::Result<()> {
    let dir = base.join(&built.snapshot.id);
    std::fs::create_dir_all(&dir)?;

    let attempt = || -> io::Result<()> {
        std::fs::write(dir.join("clean.png"), &built.clean_bytes)?;
        std::fs::write(dir.join("annotated.png"), &built.annotated_bytes)?;
        let json = serde_json::to_vec_pretty(&built.snapshot)
            .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;
        std::fs::write(dir.join("snapshot.json"), json)?;
        Ok(())
    };

    if let Err(e) = attempt() {
        let _ = std::fs::remove_dir_all(&dir);
        return Err(e);
    }
    Ok(())
}
```

```rust
/// Deletes immediate subdirectories of `base` whose mtime is older than
/// `max_age`. Per-entry failures are logged via `eprintln!` and skipped.
/// Returns the number of directories successfully removed.
pub fn cleanup(base: &Path, max_age: Duration) -> io::Result<usize> {
    let mut removed = 0usize;
    let now = std::time::SystemTime::now();

    for entry in std::fs::read_dir(base)? {
        let entry = match entry {
            Ok(e) => e,
            Err(e) => {
                eprintln!("[glitch-spot persist] read_dir entry error: {e}");
                continue;
            }
        };

        let path = entry.path();
        let metadata = match entry.metadata() {
            Ok(m) => m,
            Err(e) => {
                eprintln!(
                    "[glitch-spot persist] metadata error on {}: {e}",
                    path.display()
                );
                continue;
            }
        };

        if !metadata.is_dir() {
            continue;
        }

        let mtime = match metadata.modified() {
            Ok(t) => t,
            Err(e) => {
                eprintln!(
                    "[glitch-spot persist] mtime error on {}: {e}",
                    path.display()
                );
                continue;
            }
        };

        let age = now.duration_since(mtime).unwrap_or(Duration::ZERO);
        if age <= max_age {
            continue;
        }

        match std::fs::remove_dir_all(&path) {
            Ok(()) => removed += 1,
            Err(e) => eprintln!(
                "[glitch-spot persist] failed to remove {}: {e}",
                path.display()
            ),
        }
    }

    Ok(removed)
}
```

```rust
// ABOUTME: Filesystem writes live in crate::snapshot::persist, not here.

use std::path::Path;

use chrono::Utc;

use crate::capture::CapturedFrame;
use crate::snapshot::annotate::{render_annotated_png, AnnotateError};
use crate::snapshot::{new_id, Annotation, Context, Coords, Images, OsInfo, ScreenInfo, Snapshot};

/// One annotation as received from the React side. Coordinates are CSS pixels
/// relative to the overlay's content area; we multiply by `scale_factor` to
/// get physical pixels for the on-disk image.
#[derive(Debug, Clone, serde::Deserialize)]
pub struct IncomingAnnotation {
    pub id: String,
    pub x: f32,
    pub y: f32,
    pub w: f32,
    pub h: f32,
    pub note: String,
}

/// The output of a pure snapshot build: a `Snapshot` plus the PNG bytes whose
/// paths are recorded in `snapshot.images.{clean,annotated}`. Written to disk
/// by `crate::snapshot::persist::write`.
#[derive(Debug)]
pub struct BuiltSnapshot {
    pub snapshot: Snapshot,
    pub clean_bytes: Vec<u8>,
    pub annotated_bytes: Vec<u8>,
}

#[derive(Debug, thiserror::Error)]
pub enum BuildError {
    #[error("annotate: {0}")]
    Annotate(#[from] AnnotateError),
}

/// Assemble a `BuiltSnapshot` from the captured frame + incoming annotations.
/// Pure function — no filesystem writes. The embedded `images.{clean,annotated}`
/// paths are computed as `{base_dir}/{id}/clean.png` and `…/annotated.png`,
/// matching the layout that `persist::write` will materialise.
pub fn build(
    frame: &CapturedFrame,
    mode: &str,
    annotations: Vec<IncomingAnnotation>,
    os_platform: &str,
    os_version: &str,
    base_dir: &Path,
) -> Result<BuiltSnapshot, BuildError> {
    let id = new_id();
    let dir = base_dir.join(&id);
    let clean_path = dir.join("clean.png");
    let annotated_path = dir.join("annotated.png");

    let scale = frame.scale_factor;
    let annotations: Vec<Annotation> = annotations
        .into_iter()
        .map(|a| Annotation {
            id: a.id,
            shape: "rect".into(),
            coords: Coords {
                x: a.x * scale,
                y: a.y * scale,
                w: a.w * scale,
                h: a.h * scale,
            },
            note: a.note,
        })
        .collect();

    let annotated_bytes = render_annotated_png(&frame.png, &annotations, frame.scale_factor)?;

    let snapshot = Snapshot {
        id,
        created_at: Utc::now().to_rfc3339_opts(chrono::SecondsFormat::Secs, true),
        mode: mode.to_string(),
        annotations,
        context: Context {
            screen: ScreenInfo {
                width: frame.width,
                height: frame.height,
                scale_factor: frame.scale_factor,
                display_index: frame.display_index,
            },
            os: OsInfo {
                platform: os_platform.to_string(),
                version: os_version.to_string(),
            },
        },
        images: Images {
            clean: clean_path.to_string_lossy().into_owned(),
            annotated: Some(annotated_path.to_string_lossy().into_owned()),
        },
    };
    Ok(BuiltSnapshot {
        snapshot,
        clean_bytes: frame.png.clone(),
        annotated_bytes,
    })
}
```
