# Reject foreign Host and browser Origin on the MCP server

## Engineering

`local_only(router, port)` in `src-tauri/src/mcp/server.rs` wraps the whole MCP router. It runs before routing and body parsing. It accepts a request only if the request has exactly one raw `Host` header equal to `127.0.0.1:<port>` or `localhost:<port>` (the hostname is not case-sensitive, and a Host with no port is accepted only on port 80). Any request with an `Origin` header gets 403. The port is the configured `[mcp].port`. The guard reads the raw header and not the axum `Host` extractor, because that extractor obeys `X-Forwarded-Host`. The standalone example guards its `/test/inject` route too.

The wait cursor check moved into `SnapshotStore::wait_for_next`, after `borrow_and_update()`, so a snapshot published during a retry is no longer lost. The skill waiter always sends `last_seen_id` after a `pending` answer. `serverInfo.version` comes from `CARGO_PKG_VERSION`.

## User value

A web page that the user opens can no longer use DNS rebinding to read snapshots (notes, window titles, paths) or cancel a waiting agent. A snapshot saved while Claude Code retries its wait always reaches the agent.

## Initiative positioning

This is the MCP guard stage of the Glitch Spot security and performance review. Parallel stages handle hygiene, redaction integrity, the tray redraw loop, snapshot privacy, and pixelated redaction. Share links and the frame path come after those stages.
