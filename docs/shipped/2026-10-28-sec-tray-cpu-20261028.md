# Tray icon: no frame timer in static mode, 4 Hz pulse in animated mode

## Engineering
- `src-tauri/src/tray.rs`: the tick logic moves from `run_tray_animation` into `TrayAnimator`. `tick` returns the delay to the next frame, or `None` in static mode, so the loop arms its frame timer only in animated mode. Static mode redraws only on the 3 s health poll or a tray-appearance change.
- The animated pulse ticks at 250 ms (10 frames, 2.5 s cycle) instead of 100 ms. Glitch bursts keep 100 ms steps, and the gaps between bursts keep about the same seconds.
- One `icon_bytes` function maps a draw key to icon bytes for `setup_tray` and the loop, so the first icon and the animator agree.
- `src-tauri/src/settings.rs`: `save_tray_appearance` notifies a `tokio::sync::Notify`, so a menu change wakes the loop at once.

## User value
Each tray `set_icon` encodes a PNG on macOS, so the default animated icon used CPU all day. On idle release builds, animated mode used 2.76 s of CPU per minute on main and 1.24 s on this branch. Static mode stays at about 0.01 s per minute. The coloured icon still turns red when the MCP server is down.
